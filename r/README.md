# rios

R port of the Python package [`pyios`](../README.md): reference equations for **impulse
oscillometry (IOS)**. Given age, height, weight and sex it returns the predicted value,
% predicted, z-score and lower/upper limits of normal (LLN/ULN) for a parameter, using one of
five published reference sets (Moitra 2020, Oostveen 2013, Schulz 2013, Berger 2021,
Gochicoa-Rangel 2023). The API, flag messages and numerical results mirror the Python package.

Base R only (no dependencies beyond `utils` and `stats`).

## Install

```r
# install.packages("remotes")   # once
remotes::install_github("mithrylblade/pyios", subdir = "r")
```

To install from a local clone (run from the repository root):

```r
install.packages("r", repos = NULL, type = "source")   # or: devtools::install("r")
```

### Check the installation

```r
library(rios); OscillometryReference("gochicoa2023")
```

## Single subject

```r
library(rios)

reference <- OscillometryReference(equation = "gochicoa2023")

results <- reference$calculate(age = 50, height = 175, weight = 80, sex = "male",
                               param = "R5", value = 0.30)
results$predicted; results$percent_predicted; results$z_score
results$lln; results$uln; results$flag
```

`calculate()` returns a one-row data frame. `value` (the measured result) is optional.

## Whole data frame

```r
results <- reference$compute(
  df,
  param = "R5",
  sex_col = "sex", age_col = "age", height_col = "height", weight_col = "weight",  # defaults
  param_col = "R5"
)
df <- cbind(df, results)
```

Returns a data frame with `predicted`, `percent_predicted`, `z_score`, `lln`, `uln` and `flag`
(`prefix = "R5_"` prefixes them).

## Differences from the Python API

* Unavailable values are `NA` (Python: `None`/`NaN`); a valid result has `flag = NA`.
* `calculate()` returns a data frame row, not a dataclass. `result$predicted` works the same.
* Everything else - equation/sex/parameter spelling variants, units (`age_unit`, `height_unit`,
  `weight_unit`, `result_unit`), fallbacks, flag wording, `Z95 = 1.6449` - is identical. See the
  Python README for the full description of units, flags and how the statistics are computed.

## Data

`inst/extdata/reference_equations.csv` and `reference_metadata.csv` are copies of the files in
`src/pyios/data/`. Keep them in sync with `data-raw/sync_data.sh` (the Python test-suite fails
if they differ).

## Tests

```r
devtools::test("r")          # or: R CMD build r && R CMD check rios_0.1.0.tar.gz
```

`tests/testthat/test-golden.R` checks ~780 cases against `golden.csv`, which is generated by
the **Python** package (`PYTHONPATH=src python3 r/data-raw/make_golden.py`), so passing it
means the R and Python implementations agree on values and flag messages.
